# 咨询式论证与版面：从问题组织证据

用于财务、战略、经营与咨询分析演示，也可在分析报告中借用。这里提供推导方法和实例，不是页型白名单；不强制整篇采用咨询外观。风格、颜色与字体仍由用户选定方向决定。

## 1. 从论证开始，不从页面外壳开始

先确定本次汇报要帮助受众理解或决定什么。每页写明主信息、证据及其关系，再分配空间。例如“发生了什么 → 由哪些变化解释 → 对判断有什么影响 → 下一步与不确定性”可以构成论证链；材料只够描述事实时，不强补原因或行动建议。

分析内容页的标题尽量表达有依据的发现，而不是只写“收入分析”“客户结构”。标题可被证据检验，保留时间、范围与必要限定；相关性不写成因果，预测与假设不写成事实。封面、章节、开放问题和方法说明可以用主题标题，无需每页强行写结论。

逐页简记在 design-direction.md 中，不增加用户审批：

| 页/段 | 主信息或问题 | 证据关系与主视觉 | 空间安排 | 动效阶段 |
|---|---|---|---|---|
| 自行编号 | 受众应带走什么 | 比较、趋势、贡献、选择等；依据在哪 | 哪个区域主导，哪些说明紧邻对象 | 稳定框架、变化对象、重点与收束 |

这是编写作品时使用的计划，不显示在成品中。先看全篇计划，辨别是否只是所有页沿用同一个侧栏、卡片组和导语段落；内容问题相同的可比较页允许重复结构，问题不同则重新推导。没有强制布局数量或每页必须不同的配额。

## 2. 让证据关系决定空间结构

下面是组织关系，不能转换成固定尺寸模板或登记 ID。

| 要回答的问题 | 可采用的空间关系 | 要避免的退化 |
|---|---|---|
| 一个关键趋势及其转折 | 宽幅趋势图；关键点旁放短注释；局部细节可紧邻放大 | 大段固定侧栏挤压横轴，正文重复图上所有数字 |
| 几个维度共同解释现象 | 对齐小多图，共同时间/类别；短解释与对应图对齐 | 为了同样面积把不同量纲强行叠成双轴或相同卡片 |
| 增减怎样形成终点 | 主桥接/瀑布图；贡献、终点及局部解释成组 | 每个变化做一张 KPI 卡，累积关系消失 |
| 谁领先、差距在哪 | 排序条形/点图或比较表；差距标注靠近对象 | 所有类别各自一条满长底轨，看不出共同总量和差距 |
| 整体由什么构成 | 构成条形/堆叠及少量直标；需要时对比不同群体 | 一个小环形放在很大的白色容器里，其余空间被无关说明填充 |
| 选择哪个方案、依据是什么 | 有定义轴的矩阵或带共同评价维度的决策表；建议与依据相邻 | 为了好看虚构评分或象限位置，所有优点写成对等卡片 |
| 系统如何运作或推进 | 依赖/流程/泳道按真实关系展开；说明靠近步骤 | 大箭头串起没有依赖的口号，固定三个节点 |

核心绘图需要足够空间来承载长标签、单位、比较和注释。用留白、邻近、共同基线与细分隔建立分组，只有独立模块确有边界含义时才加容器；阴影和大白卡不是证据区的默认边界。

标题、图表标题、标签、解释、口径与来源形成清楚层级。图表标题可直接表达发现，方法名/单位放较轻的一层。注释指向具体证据，不再把同一句结论重复写进标题、导语、KPI、图注和底部总结。需要精确查数时保留表格，避免“图表下必须加完整表格”造成冗余。

图形编码、标签与数据系列规则见 [内容布局与图表](content-layout-charts.md)。品牌强调可以聚焦发现；真实系列映射不因某页重点改变而换色。来源脚注在稳定位置，针对具体图的口径紧邻对应图，不能用隐蔽 hover 承载重要限定。

## 3. 风格身份与分析结构分开

共同身份来自字体角色、颜色、页边距、标题层级、线条与注释语法。封面/章节可以用更强的品牌表现；内容页让证据成为主体。可以缩小刊头、减少重复装饰、改用通栏图表而保持原选定色温和字体。财经报刊不等于每页报头、首字下沉、背景格线和固定侧栏全部出现。

明亮咨询分析是一种可推荐的视觉方向，配色唯一来源为 style-library.md。咨询式论证也能与财经报刊、研究图册、瑞士网格等选定体系结合；不能借“参考麦肯锡”擅自将用户已选作品全部改成蓝白。

## 4. 一个组织推导例子

以“业务构成与客户层级”材料为例，先确认二者的分母与口径。二者来自不同分类，不能画连线暗示哪种产品由哪类客户贡献，也不能仅靠客户收入占比推出客单价或盈利质量。

若主信息是“大型客户构成主要收入来源”，让客户分类比较成为主证据：长标签共用左对齐轴、金额/比例直接标注，重点对象有局部强调。产品收入构成作为另一项上下文，用紧凑的完整构成图及口径表达；如两项发现都需要充分讨论，可拆页，或为各自保留独立区域。无需固定“左导语、右环形＋进度条”。

换到季度逆转，应重做空间关系：季度共用时间框架，盈利与现金流证据按真实口径关联，异常季度附近放解释。换到增长贡献，应突出累计桥接。三页仍可沿用同一字体、酒红强调、纸色与注释语言。这是按证据重组，不是每页随机换外观。

演示的实际播放由 [语义动效](semantic-motion.md) 定义；静态报告不能证明某种动画是机构官方实践。

## 5. 公开样本与适配边界

查阅：2026-09-30。选择的是公开报告原件，不是内部客户 PPT 母版；不复制 Logo、完整页面、品牌字体或资产。以下是本 skill 对样本的观察，具体结构建议是改编。

| 来源 | 定位与观察 | 借鉴方式 |
|---|---|---|
| W11 · [McKinsey：Global Banking Annual Review 2025](https://www.mckinsey.com/~/media/mckinsey/industries/financial%20services/our%20insights/global%20banking%20annual%20review%202025/why-precision-not-heft-defines-the-future-of-banking.pdf) | PDF 第10页 / 印刷页9，Exhibit 3：三项收入、余额、利润率相关趋势配编号解释，图题表达发现，口径/来源完整；本次读取图表结构与正文 | 多项证据共同回答问题，解释与图中对象对应；不照搬这些图的单位、范围或数值 |
| W12 · [BCG：Global Wealth Report 2025](https://web-assets.bcg.com/89/d4/676a2c534cf2aa485011edbc0200/2025-global-wealth-report-june-2025.pdf) | PDF 第5页 Exhibit 1 与第9页 Exhibit 4：地区、资产及增长来源采用共同类别与比较结构，数值/口径随图提供；本次读取图表结构与正文 | 同一比较问题保持共同框架；高密度图按证据关系分组，不为简洁删掉比较维度 |
| W13 · [Bain：Global Private Equity Report 2025](https://www.bain.com/globalassets/noindex/2025/bain-report_global-private-equity-report-2025.pdf) | PDF 第43–44页 / 印刷页41–42，Figure 1–2；已渲染观察：预测/实际分组柱；下一页用贡献桥接加分位表现，两组证据支持同一发现。绘图区开放，图题/数值/来源有层级 | 根据同一主张需要的证据改变图的组合与面积；保留准确的共同基线及贡献关系 |

这些竖向报告适合参考论证、图表与注释组织，不能把整页缩进 16:9 舞台。中文标题、密度和投影读数需重新排布。三家机构并不共享一个“万能咨询模板”，本 skill 的浅色配色和 HTML 动效均是自行设计，不冒称官方规范。
